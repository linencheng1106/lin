## 作业2：

- 变量定义和作用范围  
`main()` 里的变量是局部变量，只能在 `main()` 的 `{}` 内使用，例如：
  ```c_cpp
  uint8_t current_led = 2U;
  uint16_t delay_ms = DELAY_MS;
  const uint8_t led_count = LED_COUNT;
  ```
  
  `blink_led()` 里的 `uint16_t i = 0U;` 也只能在 `blink_led()` 内使用。离开函数或所在的 `{}`，这些变量名就不能再访问。
  
  似乎本工程文件无全局变量的使用。
- 函数声明与函数定义  
文件前面的：
  ```c_cpp
  void blink_led(uint8_t led_num, uint16_t times, uint16_t delay_ms);
  void beep(uint32_t beep_ms);
  ```
  
  是函数声明，先告诉编译器函数叫什么、接收什么参数。
  
  文件后面的：
  ```c_cpp
  void blink_led(...)
  {
    ...
  }
  ```
  
  和：
  ```c_cpp
  void beep(...)
  {
    ...
  }
  ```
  
  是函数定义，里面的 `{}` 才是函数实际做的事情。
- 形参与实参  
调用：
  ```c_cpp
  blink_led(current_led, blink_times, delay_ms);
  ```
  
  这里的 `current_led`、`blink_times`、`delay_ms` 是实参，即调用时传入的实际值。
  
  函数定义中的：
  ```c_cpp
  void blink_led(uint8_t led_num, uint16_t times, uint16_t delay_ms)
  ```
  
  `led_num`、`times`、`delay_ms` 是形参，即函数内部用来接收值的变量。
- `for` 用在哪里  
在 `blink_led()` 中控制闪烁次数：
  ```c_cpp
  for (i = 0U; i < times; i++)
  ```
  
  每循环一次，就点亮、延时、熄灭、再延时一次。
- `while` 用在哪里  
`main()` 的 `while (1)` 是无限循环，让程序一直运行。  
里面的：
  ```c_cpp
  while (current_led <= led_count)
  ```
  
  用来依次控制 LED 2 到 LED 4。
- `if` 用在哪里  
`blink_led()` 里检查 LED 编号是否超过最大数量：
  ```c_cpp
  if (led_num > LED_COUNT)
  ```
  
  `main()` 里用 `if / else` 判断并改变延时时间：
  ```c_cpp
  if (delay_ms > 100U)
    delay_ms += 20U;
  else
    delay_ms = DELAY_MS;
  ```
- `switch` 用在哪里  
`switch` 不在 `main.c`，而在 `hardware/src/led.c` 的 `led_on()`、`led_off()` 中。根据 `led_num` 是 1、2、3 还是 4，选择对应 LED 操作。
