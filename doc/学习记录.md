### 配置 Keil 工程的完整步骤、遇到的报错和解决办法

1. 安装好对应所需驱动和软件
2. 初次尝试编译与下载
3. 完成 user 组件的添加
4. 在 main.c 里补上 include
5. 把 user/src/user_beep.c 添加进这个 user
6. 在 Options for Target -> C/C++ -> Include Paths 里加上 ..\user\inc
7. 打开 Core/Src/main.c，把 // 在这里替换成#include user_beep.h 这行改成 #include "user_beep.h"
8. 再次编译与下载，已产生变化
9. 尝试移除已经在工程里的 hardware 文件，编译看报错：
